# Weather-app
## Project Description

The Smart City Weather Dashboard is a web application that displays real-time weather data and a 5-day forecast using the OpenWeatherMap API. It also provides basic suggestions such as what to wear based on current weather conditions.

## Features

* Search weather by city name
* View current weather details
* Display 5-day forecast
* Provide weather-based suggestions
* Dynamic background based on temperature
* Detect user location using Geolocation API

## Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API
* OpenWeatherMap API

## API Used

https://openweathermap.org/api

## Project Structure

* index.html
* style.css
* script.js

## How to Run

1. Clone the repository
2. Open index.html in a browser
3. Add your API key in script.js
